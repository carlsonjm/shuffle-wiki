## Where it is

On most keyboards it sits at the bottom left, between <kbd>Ctrl</kbd> and <kbd>Alt</kbd>, and shows the Windows logo. On a Mac keyboard it's the <kbd>Command</kbd> key. Some keyboards print a different logo there, but it's the same key.

## Other names for the same key

| Where you read it | What they call it |
| --- | --- |
| Shuffle, KDE Plasma and this wiki | Meta |
| GNOME, Ubuntu and many Linux guides | Super |
| Windows | The Windows key |
| A Mac keyboard | Command |

So when a guide elsewhere says <kbd>Super</kbd> + <kbd>E</kbd>, it means the same as <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>E</kbd> here.

## What it does in Shuffle

| Press | What happens |
| --- | --- |
| <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> on its own | Opens Search |
| <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>I</kbd> | Opens Shuffle Settings |
| <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>E</kbd> | Opens Files |
| <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>S</kbd> | Shows every open app at once (Spread) |
| <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>/</kbd> | Shows every keyboard shortcut |
