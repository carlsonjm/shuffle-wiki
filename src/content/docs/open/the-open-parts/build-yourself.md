Each project's page on GitHub has its own steps to build and install it. Start from the project's README, the page GitHub shows first. [The open parts of Shuffle](/open/the-open-parts/the-open-parts/) links to each one.

## What you look after yourself

When you build a part yourself, keeping it working is yours to do:

1. When KDE releases a new Plasma, rebuild the part against it and check that it still works.
2. Watch the project for fixes, and rebuild when they arrive.
3. If something breaks after an update, you roll back yourself.

:::note
These projects have no human support. To report a problem, open an issue on the project's GitHub page.
:::
