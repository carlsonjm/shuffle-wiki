You don't need a Shuffle key to use them. Each one has its own project on GitHub.

| On your screen | Project | What it does |
| --- | --- | --- |
| Cards | [Kadunce](https://github.com/carlsonjm/kadunce) | Arranges windows as cards and Stacks |
| Search | [Tettegouche](https://github.com/carlsonjm/tettegouche) | Finds apps, files and Helpers |
| Status | [Temperance](https://github.com/carlsonjm/temperance) | The status bar along the top |
| Notes | [Gooseberry](https://github.com/carlsonjm/gooseberry) | Notes on the desktop |
| Shuffle Keyboard | [shuffle-keyboard](https://github.com/carlsonjm/shuffle-keyboard) | The on-screen keyboard |

Kadunce, Tettegouche, Temperance and Gooseberry are licensed under the GPL, version 2 or later. The Shuffle Keyboard carries KDE's licence, as the keyboard it grew from does.

## What a Shuffle key adds

The key pays for Shuffle as one maintained desktop. Every part is built and tested together, new Plasma versions wait until every part works with them, and updates arrive signed and ready to use. See [Build and run them yourself](/open/the-open-parts/build-yourself/) for what you take on without one.
