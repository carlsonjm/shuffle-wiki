Microsoft Office doesn't install here. ONLYOFFICE opens and saves Office files and looks much like Office. If you picked it in Set up, you already have it.

1. Open **Discover**, the app store: press <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd>, type **Discover** and tap it. Not there at all? See [Add the app store](/apps/getting-apps/add-app-store/).
2. Search for **ONLYOFFICE**, click it, then **Install**.
3. Now double-click any Word, Excel or PowerPoint file in **Files** (<kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>E</kbd>), and it opens in ONLYOFFICE.

:::note
LibreOffice, also in Discover, is the other choice.
:::
