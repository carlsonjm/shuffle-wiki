Cards is made for one version of Plasma's window manager at a time. Plasma's updates don't wait for Shuffle, so sometimes an update brings a new Plasma before the matching Cards is ready.

When that happens, nothing breaks. Your windows open as ordinary Plasma windows and everything else in Shuffle keeps working. Cards stays off until the matching version arrives.

1. Press <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd>, type **Check for updates**, and open it. See [Keep the computer up to date](/apps/getting-apps/update-apps/).
2. Once it has finished, sign out and back in. Cards comes back on.

If Cards is still off afterwards, the matching Cards has not arrived yet. Run Check for updates again later.
