Press <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>/</kbd> at any time to see every shortcut on screen. Press it again, or <kbd>Esc</kbd>, to put it away.

| To do this | Press |
| --- | --- |
| Open or close Search | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> |
| Open Shuffle Settings | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>I</kbd> |
| Show every shortcut | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>/</kbd> |
| Spread | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>S</kbd> |
| Table | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>W</kbd> |
| Apps | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>G</kbd> |
| Files | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>E</kbd> |
| Side by side | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>B</kbd> |
| The card before or after | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Left</kbd> or <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Right</kbd> |
| The next or previous card in a Stack | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Tab</kbd> or <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Make a side-by-side card fill the screen, or put it back beside the other | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Shift</kbd> + <kbd>Up</kbd> or <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Shift</kbd> + <kbd>Down</kbd> |
| Stack the card onto the one used before | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> |
| Move the front card back or forward in its Stack | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Shift</kbd> + <kbd>Page Down</kbd> or <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Shift</kbd> + <kbd>Page Up</kbd> |
| Take the Active card out of its Stack | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Shift</kbd> + <kbd>Down</kbd> |
| Turn Cards off or on | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Esc</kbd> |
| Make one card an ordinary window, out of its Stack | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Shift</kbd> + <kbd>Backspace</kbd> |
| The workspace beside | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Ctrl</kbd> + an arrow key |
| Workspace 1 to 9 | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>F1</kbd> to <kbd>F9</kbd>, or <kbd>Ctrl</kbd> + <kbd>F1</kbd> to <kbd>F9</kbd> |
| Move the card to the workspace beside | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Left</kbd> or <kbd>Right</kbd> |
| The first to ninth app on the Actions Panel | <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>1</kbd> to <kbd>9</kbd> |
| End a frozen app | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Esc</kbd> |
| Restart, shut down or log out | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Del</kbd> |

## Change a shortcut

Press <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>I</kbd> to open Shuffle Settings, then choose **Shortcuts**.
