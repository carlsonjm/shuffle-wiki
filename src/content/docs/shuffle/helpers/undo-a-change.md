1. Press <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> to open Search, type **What changed**, and tap it.
2. Find the change in the list.
3. Tap **Undo** beside it.

The change is put back as it was. If a file has changed since, it is left as it is and nothing is put back.

A setting that changed can be put back the same way with **Put back** on its row. **Copy for help** copies exactly what changed, to paste wherever you ask for help.

To go back further, open **Restore points** from Search the same way.
