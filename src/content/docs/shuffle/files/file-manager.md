When you set up Shuffle, Files becomes the computer's file manager. Whenever another app asks to show a folder, Files opens it. For example:

- **Show in folder** in a web browser's downloads opens Files with the download chosen.
- **Open with File Manager** for a drive in Plasma opens that drive in Files.
- A plugged-in phone and the Trash open in Files too.

Network shares still open in **Dolphin**, KDE's own file manager, which stays installed.

If <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>E</kbd> opens Dolphin instead of Files, Dolphin is holding that key. Open **System Settings**, choose **Shortcuts**, find **Dolphin**, and clear its <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>E</kbd>. After that, <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>E</kbd> opens Files.
