- **In this folder:** open Files with <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> + <kbd>E</kbd> and type part of the name. Files shows only what matches.
- **In every folder inside it:** type the name, then press <kbd>Enter</kbd>, or tap **Search inside folders**. Results arrive as it looks, each with the folder it is in. Tap **Stop searching** to keep what it found so far, and **Back** to return to the folder.
- **Something you used lately:** tap **Recent**. It shows the 30 files and folders you used last, newest first.
- **From anywhere:** press <kbd><a href="/start/first-steps/meta-key/">Meta</a></kbd> and type the name in [Search](/shuffle/search/search/). Search finds files by name, and by the words inside them.

To open the folder a file is in, right-click it in Recent or in the results and choose **Show in folder**.
